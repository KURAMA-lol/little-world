# Little World

A polished, vector-rendered isometric settlement simulator for Android. Begin with one cottage and grow from a homestead into a village, town, city and eventually a country.

## Included in the first playable build
- Landscape Android interface and crisp, resolution-independent vector scene (not pixel art).
- Place houses, roads, farms, parks and markets.
- Residents move around the map and have names and roles.
- Population growth, homes, coins, day progression and settlement tiers.
- Pause and simulation speed controls.
- Local progress persistence.

## Progression
| Stage | Population |
|---|---:|
| Homestead | 1–3 |
| Village | 4–8 |
| Town | 9–19 |
| City | 20–44 |
| Country | 45+ |

## Build
`gradle assembleDebug`

GitHub Actions builds a release APK on pushes to main. Pushing a `v*` tag builds and publishes an APK in GitHub Releases.

## Roadmap
Citizen needs, schedules, relationships, family trees, richer building catalogues, zoning, utilities, regional maps, multiple settlements, transport, seasons, events and country-level systems.
